# SpaceDC

## Описание
Проект представляет собой удобное приложение для студентов, позволяющее быстро находить и бронировать свободные аудитории в учебных заведениях. Пользователи могут просматривать доступное время, выбирать подходящие помещения и резервировать их в несколько кликов. Система помогает эффективно использовать пространство и упрощает организацию учебной и групповой работы.
